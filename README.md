# 超级马里奥

纯 HTML5 Canvas 实现的经典超级马里奥游戏。

## 运行方式

直接用浏览器打开 `index.html` 即可。

## 操作说明

| 按键 | 功能 |
|------|------|
| ← → | 左右移动 |
| 空格 / ↑ | 跳跃 |
| R | 重新开始（游戏结束/通关后）|

## 游戏规则

- **小马里奥** → 吃蘑菇变 **大马里奥**
- 大马里奥被碰 → 变回小马里奥
- 小马里奥被碰 → 扣一条命
- 初始 3 条命，命空 Game Over
- 踩板栗仔头顶消灭（+100 分）
- 拾取金币 +200 分
- 到达旗杆通关 +5000 分

## 技术实现

- 纯前端，无需任何依赖
- Canvas 像素风格渲染
- AABB 碰撞检测
- 重力物理系统
- 横向镜头跟随滚动
